# ARCIUM

ARCIUM — production-ready статический браузерный игровой хаб для GitHub Pages. Проект восстановлен без старых исходников и работает без backend и обязательной регистрации.

## Что внутри

- Главная страница с hero-блоком, поиском, категориями, каталогом карточек и детерминированной «Игрой дня».
- 17 играбельных игр: Змейка, 2048, Сапёр, Реакция, Понг, Арканоид, Орбита, Мемори, Камень-Ножницы-Бумага, Пятнашки, Tower Stack, Dino Runner, Aim Trainer / Тир, Судоку, Морской бой, Линии 98, Pacman.
- Локальный профиль гостя: ник, аватар, XP, уровни/ранги, статистика, рекорды и достижения.
- Ранги: Нова → Бронза → Серебро → Золото → Платина → Легенда.
- Экспорт/импорт прогресса JSON через `localStorage`.
- Локальный leaderboard. Он намеренно не называется глобальным, потому что backend пока отсутствует.
- Sharing после результата: Web Share API с fallback через Clipboard.
- Вау-фишки: конфетти за рекорд, лёгкий 3D tilt, CRT mode, Konami code с секретной игрой, `prefers-reduced-motion`, `navigator.vibrate`, touch/D-pad управление и подготовленная структура под сезонные темы.
- Dark/Light темы.
- Адаптивная верстка для ПК, планшета и телефона.

## Запуск

Откройте `index.html` напрямую в браузере или запустите любой статический сервер в корне репозитория.

```bash
npm test
```

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует статический сайт из корня репозитория при push в `main`. В настройках репозитория нужно выбрать GitHub Pages source: **GitHub Actions**.

Ожидаемый адрес после включения Pages:

```text
https://artyom4uk.github.io/ARCIUM/
```

## Архитектура аккаунтов

Сейчас реализован честный гостевой local-first режим без фальшивой авторизации. Для будущего подключения backend предусмотрены следующие направления:

- e-mail magic link или OTP;
- логин + пароль через серверную проверку и безопасное хеширование паролей на backend;
- Google OAuth.

Для Google OAuth понадобится создать OAuth Client ID в Google Cloud Console и добавить его в будущий auth-конфиг frontend/backend. Без Client ID и backend сайт не имитирует вход через Google, чтобы не вводить пользователя в заблуждение.

## Будущий глобальный leaderboard

Текущая таблица лидеров хранится локально на устройстве. Для глобального leaderboard нужно добавить backend API, например:

- `POST /scores` — отправка результата с подписью/проверкой сессии;
- `GET /scores?game=snake` — таблица по игре;
- античит-валидация и rate limits;
- авторизация пользователя или гостевой device id.

## Производительность

Проект сделан на vanilla HTML/CSS/JS без тяжёлых библиотек, видео-фонов и 3D-движков. Игровые циклы запускаются только внутри модального окна игры и останавливаются при закрытии/рестарте.
